#### Descripcion
este es un proyecto juego puzzle tetris un juego clasico en el cual existe movimiento, puntuacion y coliciones.

#### herramientas
se utilizo IA Cursor con cloude para generar codigo funcional en la app aproximadamente el 80%
Se utilizo react
Se utilizo bootstrap 5 , icons
